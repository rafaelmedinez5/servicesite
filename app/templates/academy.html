Curriculum

What the three-month program covers

Month 01

Foundations

  • Authorization, scope, rules of engagement, and evidence handling
  • Networking, HTTP, Linux, Windows, and identity fundamentals
  • Python and shell automation for repeatable assessment tasks
  • Threat modeling, vulnerability triage, and risk communication
  • Clear technical notes and defensible findings
Month 02

Offensive security tools

  • Authorized reconnaissance and attack-surface mapping
  • Web and API assessment methodology in controlled labs
  • Network and endpoint validation with safe test procedures
  • Exploit analysis and secure proof-of-concept development
  • Evidence capture, remediation mapping, and retesting
Month 03

Real-world operations

  • Engagement planning, communication, and operational safety
  • Identity and directory-security scenarios in isolated ranges
  • Purple-team validation and detection-aware testing
  • Executive and technical report construction
  • Capstone assessment under a documented rules-of-engagement plan
